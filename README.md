## Модель ветвления (Git flow)

В проекте использована модель Git flow:

- `main` — стабильная версия проекта;
- `develop` — основная ветка разработки;
- `feature/*` — ветки для отдельных задач (ответвляются от `develop`);
- `release/*` — подготовка релиза (ответвляется от `develop`, сливается в `main` и `develop`);
- `hotfix/*` — срочные исправления (ответвляется от `main`, сливается в `main` и `develop`).

Схема слияний:

feature/new-feature → develop  
feature-main → develop  
release-1.0 → main, develop  
hotfix-1.0.1 → main, develop  
develop → main

## Установка Git-хука flake8

Хук запускает проверку стиля кода `flake8` перед каждым коммитом
и блокирует коммит при наличии ошибок.

### 1. Установить flake8

pip install flake8

### 2. Настроить Git использовать хуки из папки `.githooks`

git config core.hooksPath .githooks

### 3. Проверить, что хук работает

Измените любой `.py`-файл, добавив ошибку стиля, и попробуйте сделать коммит:

git add main.py  
git commit -m "test hook"

Если flake8 найдёт ошибки — коммит будет заблокирован.
