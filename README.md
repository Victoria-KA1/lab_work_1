\## Установка Git-хука flake8



1\. Установите flake8:

&#x20;  pip install flake8

2\. Настройте Git использовать хуки из папки .githooks:

&#x20;  git config core.hooksPath .githooks

3\. Теперь перед каждым коммитом запускается flake8 . Если есть ошибки стиля — коммит блокируется.
